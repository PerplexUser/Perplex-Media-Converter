Perplex Media Converter 1.1.6 — Windows 10/11 x64

Run Perplex-Media-Converter-Setup-1.1.6-Offline.exe and click Install now.
FFmpeg and FFprobe are included. Installation and conversion need no internet.
No administrator access is required. Installation folder:
%LOCALAPPDATA%\Programs\Perplex Media Converter
Start the app from the Start menu. Close the app before upgrading/removing it.
Uninstall through Windows Settings > Apps or uninstall.exe --uninstall.
