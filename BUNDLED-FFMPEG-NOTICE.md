# Bundled FFmpeg 1.1.6

This edition uses the FFmpeg 9.1-perplex-1.1.6 build produced from the source
archives included in Perplex-FFmpeg-Source-1.1.6.zip. The old Gyan binary is
not part of this release. See FFMPEG-MANIFEST.json for exact identification.

FFmpeg and FFprobe are GPLv3-or-later. The application's MIT license does
not cover those executables. The source ZIP must remain available next to
all release binary downloads. See FFmpeg-REDISTRIBUTION.txt.
