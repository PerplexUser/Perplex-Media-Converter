# Perplex Media Converter 1.1.6 — vollständiger Offline-Installer

Windows 10/11, 64 Bit. Installation und Konvertierung ohne Internetverbindung.
H.264/AAC-Video, MP3, Tonspurauswahl, externe Audiodateien und Vorschau.

## Downloads

- `Perplex-Media-Converter-Setup-1.1.6-Offline.exe` — Installation
- `Perplex-Media-Converter-Portable-1.1.6.zip` — entpacken und starten
- `Perplex-Media-Converter-Offline-Developer-Kit-1.1.6.zip` — selbst bauen
- **`Perplex-FFmpeg-Source-1.1.6.zip` — vollständige passende FFmpeg-Quellen**
- `SHA256SUMS.txt` — SHA-256-Prüfsummen

Die Dateien sind an dieses Release angehängt. Die FFmpeg-Quellen stehen
kostenlos mit gleichwertigem Downloadzugang zur Verfügung. Die automatische
GitHub-Datei „Source code“ ist kein Ersatz für das separate FFmpeg-Quellpaket.
